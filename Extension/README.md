# English Study · 浏览器扩展

在 PC 上阅读英文时，选中文字即可加入单词本，和手机端共用同一份收藏。

## 安装（无需上架应用商店）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本目录（`Extension/`）
4. 装好后工具栏会出现图标；建议点拼图图标把它**固定**到工具栏

Edge / Brave 等 Chromium 内核浏览器同理（`edge://extensions/`）。

## 用法

| 方式 | 操作 |
| --- | --- |
| 划词添加 | 选中英文 → 右键 → **添加到单词本** |
| 手动添加 | 点工具栏图标 → 输入单词或句子 → 添加 |

添加成功时，页面底部会弹出一条提示，显示原文和翻译。

打开扩展图标还能看到**最近 20 条**收藏（和手机端是同一份数据）。

## 和手机端的关系

```
浏览器扩展  ──┐
              ├──> 后端 /favorites/sync ──> 手机 App 收藏页（打开时自动拉取）
手机 App    ──┘
```

- 单词判定的规则、翻译走的后端接口，都和手机端一致
- 扩展写入的条目 `lessonTitle = "浏览器"`，所以在手机端列表里一眼能看出是电脑上加的
- 卸载重装手机 App 或换电脑，收藏都能拉回来

## 设置

扩展图标 → 设置，可以改后端地址（默认 `https://handwriter.asia/english`）。

改了非默认地址后，需要把这个域名加进 `manifest.json` 的 `host_permissions`，否则浏览器会拦住请求。

## 文件

| 文件 | 说明 |
| --- | --- |
| `manifest.json` | MV3 清单 |
| `background.js` | 右键菜单、翻译、写入服务端、页面提示 |
| `popup.html` / `popup.js` | 工具栏弹窗：手动添加 + 最近添加 |
| `options.html` / `options.js` | 设置后端地址 |
| `icons/` | 复用手机端 App 图标 |

设计说明见 `../docs/cells/browser-extension.md`。
